# 根目录、文档与 Agent 配置索引

返回[文件索引入口](../file-index.md)。

## 根目录

| 文件               | 定位与用途                                               | 不该出现的内容                                             |
| ------------------ | -------------------------------------------------------- | ---------------------------------------------------------- |
| `.gitignore`       | Git 跟踪白名单与产物忽略规则。                           | 业务逻辑、密钥、仅个人机器适用且会阻止项目文件入库的规则。 |
| `.prettierrc`      | 全仓库 Prettier 格式配置。                               | ESLint 规则、构建配置、局部业务格式例外。                  |
| `AGENTS.md`        | Agent 开发规则、架构边界、数据安全与验证要求的权威来源。 | 功能实现、临时任务记录、会快速过期的页面观察值。           |
| `CLAUDE.md`        | 指向 `AGENTS.md` 的符号链接，让其他 Agent 读取同一规则。 | 独立规则副本或与 `AGENTS.md` 分叉的内容。                  |
| `CHANGELOG.md`     | 面向用户的版本变更记录和未发布运行时变化。               | 开发过程日志、纯重构细节、未实际交付的设想。               |
| `LICENSE`          | GPL-3.0-only 许可证正文。                                | 项目说明、额外授权承诺、业务代码。                         |
| `README.md`        | 中文项目入口：功能、安装、开发、数据安全与支持范围。     | 内部实现流水账、选择器清单、未确认功能承诺。               |
| `bun.lock`         | Bun 解析后的依赖锁定结果，保证可复现安装。               | 手工维护的依赖说明、源码或密钥；应由 Bun 更新。            |
| `package.json`     | 包元数据、唯一版本号、脚本和直接依赖声明。               | 运行时用户数据、未使用依赖、与 Bun 脚本重复的操作文档。    |
| `eslint.config.js` | TypeScript、React Hooks、Prettier 的静态检查配置。       | 业务规则、格式化规则副本、对生成目录的扫描。               |
| `tsconfig.json`    | TypeScript 严格检查、路径别名、编译目标和输入范围。      | WXT manifest、测试用例、按功能分支的编译逻辑。             |
| `vitest.config.ts` | Vitest 的 jsdom 环境、别名和测试文件匹配规则。           | 生产构建配置、真实浏览器端到端逻辑、业务 mock。            |
| `wxt.config.ts`    | WXT、Vite 插件与 Chrome/Edge MV3 manifest 配置。         | 页面业务逻辑、非必要权限、用户数据或私密主机地址。         |
